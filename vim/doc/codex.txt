*codex.txt*  Codex integration for Vim

                  CODEX FOR VIM                       *codex*

The Codex plugin opens the Codex CLI in Vim's built-in terminal and can pass
prompts, visual selections, or text selected with Vim motions.

Requirements                                           *codex-requirements*

- The Codex CLI (`codex`) must be available in PATH.
- Vim must include the |+terminal| feature.
- Vim 9.1 or later is required for |getregion()|, used to capture selections.

Commands                                                *codex-commands*

:Codex [prompt]                                            *:Codex*
    Open an interactive Codex session.  An optional prompt is sent as the
    initial instruction.

:CodexAsk {prompt}                                      *:CodexAsk*
    Run a one-shot prompt with `codex exec`.  The terminal buffer remains open
    after Codex finishes so the response can be read.

:CodexSelection [prompt]                            *:CodexSelection*
    Send the text from the last Visual selection to `codex exec`.  The command
    accepts characterwise, linewise, and blockwise selections.  If {prompt} is
    omitted, Codex is asked to use the selected text as input.

    In Visual mode, type `:CodexSelection explain this code` to add an
    instruction for Codex.  Vim supplies the Visual range automatically.

:CodexReview                                          *:CodexReview*
    Run `codex exec review` for the current project.  The terminal buffer
    remains open after Codex finishes.

Motion operator                                         *codex-motion*

Use |gC| followed by any Vim motion or text object to send that text to Codex.
For example:

    gCiw          Send the inner word under the cursor.
    gCap          Send the current paragraph.
    gC}           Send text to the end of the paragraph.

By default, the selected text is sent with the instruction "Use the selected
text as input."  Set |g:codex_operator_prompt| to change that instruction:

    let g:codex_operator_prompt = 'Explain this code'

Project directory                                      *codex-project-root*

Codex starts in the nearest Git repository root when one is found by searching
upward from the current file.  Outside a Git repository, it starts in the
current file's directory, or Vim's current working directory when no file is
open.

See also: |terminal|, |getregion()|
